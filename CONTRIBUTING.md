# Contribuindo com o gBot

Valeu por querer ajudar! O gBot segue o mesmo modelo do VS Code: o código é aberto (licença MIT), qualquer pessoa
pode fazer fork e mexer à vontade, e as melhorias boas voltam para o projeto principal por pull request.

## Como mandar uma melhoria

1. Faça um fork e crie um branch a partir da `main`.
2. Rode `npm install` e `npm run dev` para testar. Antes de abrir o PR, `npm run typecheck` precisa passar.
3. Abra o pull request explicando o que mudou e por quê (prints ajudam muito em mudanças de tela).
4. Assine os seus commits com `git commit -s` (veja abaixo).

## Licença das contribuições

Ao enviar um pull request, você concorda que a sua contribuição é licenciada sob a mesma licença do projeto
(MIT, arquivo [LICENSE](LICENSE)) e que ela pode ser incorporada, modificada e distribuída como parte do gBot.

Para deixar isso registrado, cada commit leva a linha `Signed-off-by` (o `-s` do `git commit` adiciona sozinho).
Ela vale como a sua declaração do [Developer Certificate of Origin](https://developercertificate.org/): o código é
seu ou você tem o direito de enviá-lo sob esta licença.

## Nome e marca

O código é livre, mas o nome **gBot** e o mascote **Brasa** identificam o projeto oficial. Forks publicados são muito
bem-vindos, só use outro nome e outro ícone para ninguém confundir com a versão oficial.
